# Sistem Pencatatan & Rekapitulasi Biaya Pendidikan — Ponpes SIT Al Firdaus

Aplikasi web administrasi keuangan sekolah (Unit SMPIT & SMAIT Al Firdaus) untuk memudahkan Bendahara (**Restasari, S.Sos**) dalam pencatatan, perhitungan tunggakan akurat, pencetakan kwitansi PDF, dan pengiriman informasi tagihan ke orang tua/wali santri via WhatsApp.

## Cara Penggunaan Singkat
1. Klik tombol **Import Excel (.xlsx)** di pojok kanan atas dan pilih file `BIAYA PENDIDIKAN 2026-2027.xlsx`.
2. Gunakan filter **Cut-off Hitung Tunggakan** (misal *s.d. Oktober*) untuk menghitung total tagihan berjalan secara otomatis.
3. Klik tombol **Bayar** untuk mencatat pelunasan atau cicilan santri dan mencetak kwitansi resmi.
4. Klik ikon **WhatsApp** untuk mengirim rincian tagihan atau bukti pembayaran langsung ke wali santri.
5. Gunakan tombol **Backup Data** secara berkala untuk menyimpan salinan database ke komputer/HP.
